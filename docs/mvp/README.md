# Documentação do MVP (histórico)

Esta pasta guarda a documentação usada para construir o MVP do Food Share,
**só como registro**. Ela **não** vale para trabalho novo.

- O escopo reduzido, a numeração RF01–RF20/RNF01–RNF12 e as listas de
  "fora do escopo" daqui foram substituídos pelos arquivos na raiz de
  `docs/`.
- Para traduzir um código de requisito do MVP para a numeração atual, use a
  coluna "Código no MVP" de `docs/REQUISITOS.md`.
- O `PLANO-FRONTEND.md` daqui descreve como cada tela do MVP foi construída
  (fases F0–F8). É útil para entender o código existente, não para decidir
  o que fazer.
